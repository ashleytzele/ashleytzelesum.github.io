# A-003 Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace A-003's internship-first wide diagram and résumé rows with two extensible vertical career tracks whose role-owned details fail open and distinguish builder experience from operator responsibility.

**Architecture:** A-003 becomes two semantic ordered lists: Software / Systems and Operations / Aquatics. Each list item owns one role article, one native disclosure control, and one inline detail region; CSS presents the tracks side by side on wide screens and stacks the same markup on narrow screens, while JavaScript earns the collapsed enhanced state only after successful initialization. Decorative timeline rails and markers may reveal, but role content, dates, controls, and details remain complete in static, failure, reduced-motion, and print modes.

**Tech Stack:** Static HTML5, existing CSS custom properties, dependency-free JavaScript, Node built-in test runner, DevTools browser-measurement harness.

```js
    /* A-003 role details: static HTML is complete; successful runtime earns collapse. */
    var experienceButtons=[].slice.call(document.querySelectorAll('#a003 .experience-more'));
    var setExperienceOpen=function(button,detail,open){
      detail.setAttribute('data-open',String(open));
      button.setAttribute('aria-expanded',String(open));
      button.textContent=(open?'Close details \u2014 ':'Open details \u2014 ')+button.dataset.label;
    };
    experienceButtons.forEach(function(button){
      var detail=document.getElementById(button.getAttribute('aria-controls'));
      if(!detail)throw new Error('Missing A-003 detail for '+button.dataset.label);
      setExperienceOpen(button,detail,false);
      button.addEventListener('click',function(){
        try{setExperienceOpen(button,detail,detail.getAttribute('data-open')!=='true')}
        catch(error){resetA001();throw error}
      });
    });
```

This controller never closes a sibling detail. If initialization fails, the outer `catch` calls `resetA001()`, which removes `runtime-ready`; CSS then hides all A-003 controls and reveals all A-003 details. The script element's existing `onerror` already removes `runtime-ready` and `js` for request failure.
