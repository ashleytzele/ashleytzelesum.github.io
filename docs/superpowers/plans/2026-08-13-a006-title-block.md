# A-006 Title Block — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild A-006 as the drawing set's title block, removing the doubled
ending, the triplicated email address and the centred layout.

**Architecture:** One CSS-grid block replaces four components. Hairlines are a
1px grid `gap` over a `--line` background. Named grid areas remap at two
breakpoints, then dissolve to DOM order.

**Tech Stack:** Static HTML + CSS. No dependencies, no build step. Node's built-in
test runner.

**Spec:** `docs/superpowers/specs/2026-08-13-a006-title-block-design.md`

## Global Constraints

- No dependencies, no build step, no third-party requests.
- Run tests as `node --test` **from the repository root**. `node --test test/`
  does not work — Node resolves the directory as a module.
- A-001 through A-005 unchanged. Verify with `git diff --stat`.
- Both themes via tokens only; no colour literal outside `:root`.
- Print must not inherit the dark theme.
- Every link ≥ 44px target.
- Content is out of scope. Every value moves across unchanged; none is rewritten.
- A test counts as passing only after it has been observed to fail.

```js
// --- A-006 title block ------------------------------------------------------
const a006Of = (s) => s.slice(s.indexOf('id="a006"'));

test('A-006 shows the email address once', () => {
  // The sheet previously displayed it three times: the button, the line under
  // it, and the end block. A mailto on the action button is fine — that is a
  // labelled control, not a printed address — so this counts visible text.
  const text = a006Of(html).replace(/<[^>]+>/g, ' ');
  const shown = (text.match(/ashleysumtzele04@gmail\.com/g) || []).length;
  assert.equal(shown, 1, `A-006 prints the address ${shown} times, expected 1`);
});

test('A-006 centres nothing', () => {
  // Every sheet is left-aligned to the document grid. The old .endpage broke
  // that on the last screen of the site, which is the worst place to break it.
  const rules = css.match(/\.(?:tblock|endpage|endmeta|sig|dep)[^{]*\{[^}]*\}/g) || [];
  for (const r of rules) {
    assert.ok(!/text-align\s*:\s*center/.test(r), `centred text on A-006: ${r}`);
    assert.ok(!/margin\s*:[^;]*\bauto\b/.test(r), `auto margin on A-006: ${r}`);
  }
});

test('the components the title block replaces are gone', () => {
  for (const c of ['dep', 'endpage', 'endmeta', 'sig']) {
    assert.ok(!new RegExp(`class="[^"]*\\b${c}\\b`).test(html), `.${c} still in markup`);
    assert.ok(!new RegExp(`^\\.${c}[\\s{.,:]`, 'm').test(css), `.${c} still in stylesheet`);
  }
});

test('the title block carries every field the spec names', () => {
  const a006 = a006Of(html);
  const fields = ['Document title', 'Issued for', 'Drawn by', 'References',
    'Document no.', 'Revision', 'Sheets', 'Scale', 'Status', 'Issued', 'Location'];
  for (const f of fields) {
    assert.ok(a006.includes(`>${f}<`), `title block is missing the ${f} field`);
  }
  // every field must carry a value, not just a label
  const cells = [...a006.matchAll(/<div class="c-[a-z]+"[^>]*>([\s\S]*?)<\/div>\s*(?=<div class="c-|<\/div>)/g)];
  for (const [, body] of cells) {
    const value = body.replace(/<span class="k">[\s\S]*?<\/span>/, '').replace(/<[^>]+>/g, '').trim();
    assert.ok(value.length > 0, `empty title-block cell: ${body.slice(0, 60)}`);
  }
});
```

- [ ] **Step 5: Add the block's rules**

```css
/* A-006 title block. Hairlines are the container's --line background showing
   through a 1px grid gap, so every division is exactly one pixel and no cell
   can double its neighbour's border. Print overrides this: see the print
   block, where backgrounds are not guaranteed to render. */
.tblock{display:grid;grid-template-columns:repeat(4,1fr) 1.45fr;
  grid-template-areas:
    "title  title  title  title  drawn"
    "issued issued issued issued drawn"
    "doc    rev    sheets scale  refs"
    "status date   loc    loc    refs";
  gap:1px;background:var(--line);border:1px solid var(--line);
  margin-top:calc(var(--u)*4)}
.tblock>div{background:var(--paper);padding:calc(var(--u)*2)}
.c-title{grid-area:title;padding-top:calc(var(--u)*3);padding-bottom:calc(var(--u)*3)}
.c-issued{grid-area:issued} .c-drawn{grid-area:drawn} .c-refs{grid-area:refs}
.c-doc{grid-area:doc} .c-rev{grid-area:rev} .c-sheets{grid-area:sheets}
.c-scale{grid-area:scale} .c-status{grid-area:status} .c-date{grid-area:date}
.c-loc{grid-area:loc}
.tblock .k{font-family:'MN',monospace;font-size:8px;letter-spacing:.22em;
  text-transform:uppercase;color:var(--ref);display:block;margin-bottom:7px}
.tblock .v{font-size:.95rem;font-weight:600;letter-spacing:-.015em}
.tblock .s{font-family:'MN',monospace;font-size:.7rem;color:var(--ref);display:block;
  margin-top:5px;line-height:1.7}
.tt{font-size:clamp(1.5rem,3.4vw,2.1rem);font-weight:500;letter-spacing:-.035em;line-height:1.1}
.tt .of{display:block;font-size:.42em;font-weight:400;letter-spacing:.02em;
  color:var(--sec);margin-bottom:4px}
.issue{font-size:clamp(1rem,2vw,1.22rem);font-weight:600;letter-spacing:-.02em}
.rt{display:flex;flex-direction:column;margin-top:calc(var(--u)*1.5)}
```

**Known gap.** The empty-cell assertion in test 4 parses nested `<div>`s with a
regex, which is fragile. It is a guard against an obviously broken block, not a
parser; if it produces a false positive during implementation, simplify it to
checking that each `c-` class appears and that the sheet's text length exceeds a
floor, and record the change rather than deleting the check.
