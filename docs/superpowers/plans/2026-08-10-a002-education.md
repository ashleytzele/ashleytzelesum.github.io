# A-002 Education Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace A-002 Journey with a responsive, semantic Education route from INTI International College Subang to San Francisco State University without duplicating A-003 Experience.

**Architecture:** A-002 becomes two ordered semantic education nodes connected by decorative construction notation. One markup set reflows from a horizontal desktop/tablet route to a vertical phone route; all essential chronology remains visible text, while CSS owns only the datum, ports, direction mark, and one-time reveal motion. The existing global reveal controller remains unchanged unless a focused failing test proves it cannot draw the new A-002 details.

**Tech Stack:** Static HTML5, existing CSS custom properties, existing dependency-free JavaScript reveal controller, Node built-in test runner, DevTools browser-measurement harness.

## Global Constraints

- The approved source of truth is `docs/superpowers/specs/2026-08-10-a002-education-design.md`.
- Preserve drawing number `A-002`, anchor `#a002`, sheet position `2 of 6`, and the six-sheet architecture.
- Publicly rename A-002 from `Journey` to `Education` on every surface enumerated by the spec.
- Use exactly two education records in EDU-01 then EDU-02 DOM order; do not duplicate markup for mobile.
- Use the exact institution, programme, location, date, transfer, caption, and A-003 handoff copy from the spec.
- Do not add coursework, Dean's List, GPA, graduation date, employment events, swimming, project references, or skill tags to A-002.
- A-003 through A-006 must remain byte-identical.
- Preserve A-001 visual design, tab behavior, progressive enhancement, and accessibility. In addition to direct `Journey` naming prose, correct only the Athletics references: visible reference `A-003`, specification field `Ref drawings: A-003 · 05.6`, while keeping `Applied in: SplitWise · 05.6`.
- A-002 has no tabs, disclosures, drag, zoom, hover-only content, or JavaScript-owned local state.
- Essential A-002 content must remain visible without CSS, JavaScript, animation, or a successful script load.
- Use the existing Public Sans, Spline Sans Mono, light/dark/print tokens, and established 8.5–9px factual drawing-text floor.
- No gradients, shadows, glows, blur, rounded cards, emoji, external dependencies, or third-party requests.
- Phone layout must not require horizontal panning; responsive layouts must use one semantic record set.
- Reduced motion, no-JavaScript, script-failure, and print states must show the completed route immediately.
- Animation may draw only decorative properties; no infinite animation or layout-property animation.
- Cover composition is frozen. Update only its `Updated` value if the repository date contract requires it.
